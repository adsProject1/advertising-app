Advertisement Campaign & Field Activity Management System

A clickable HTML/CSS/JavaScript wireframe for a promotional agency that runs product promotions, mall activations and roadshows — built around a single flat Activity record, across a desktop operations console and an Android field-agent app.

Desktop Admin

Add Activities with auto-generated Activity Numbers — State, AO Name, Period and Element/Team-Van details — and review submitted field evidence.

Android Agent

This is a frontend-only prototype. There is no backend, database or real authentication — all data is mock data held in your browser's local storage, shared between both applications so actions in one are reflected in the other. See the README for demo credentials and the full user flow.
